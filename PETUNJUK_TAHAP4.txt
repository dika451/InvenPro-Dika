INVENPRO - TAHAP 4: LAPORAN INVENTARIS

Isi paket:
- index.html
- style.css
- script.js
- PETUNJUK_TAHAP4.txt

CARA PEMASANGAN:
1. Simpan backup folder InvenPro Tahap 3.
2. Salin tiga file web (index.html, style.css, script.js) dari paket ini ke folder project InvenPro.
3. Pilih Replace/Timpa jika Windows meminta konfirmasi.
4. Jangan menghapus tabel barang, transaksi_stok, bucket foto-barang, atau data Supabase.
5. Tidak ada SQL baru yang perlu dijalankan untuk Tahap 4. Fitur laporan membaca tabel barang dan transaksi_stok yang sudah digunakan Tahap 3.
6. Jalankan index.html dengan Live Server dan login seperti biasa.

FITUR:
- Laporan posisi stok barang dan estimasi nilai inventaris.
- Ringkasan total stok masuk dan stok keluar berdasarkan filter tanggal.
- Grafik perbandingan stok masuk dan stok keluar.
- Detail transaksi berdasarkan periode.
- Export Excel-compatible CSV (dapat dibuka di Microsoft Excel).
- Cetak / Save as PDF melalui dialog cetak browser.

CATATAN:
- Export Excel menghasilkan file CSV UTF-8 dengan pemisah titik koma agar lebih mudah dibuka di Excel lokal.
- Untuk PDF, klik Cetak / Simpan PDF, lalu pilih "Save as PDF" pada dialog printer browser.
- SQL tidak diperlukan karena Tahap 4 tidak membuat tabel baru atau mengubah skema database.
